# IELTS Study Companion

For IELTS study requests in Codex, Claude Code, or WorkBuddy, read `skills/ielts-study/SKILL.md` and follow its workflow. The Doubao Work chat adaptation is in `skills/ielts-study-doubao/SKILL.md` and does not provide local file access or persistent records. User-specific data belongs only in the configured private workspace; default `workspace/`. Do not read unrelated personal directories.

For code maintenance, use Python 3.10+ standard library, run `python3 -m unittest discover -s tests -v`, and keep personal and copyrighted materials out of Git. Do not initialize a study session merely because someone is editing this repository.
