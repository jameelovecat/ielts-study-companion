# IELTS Study Companion

For IELTS speaking practice, mock tests, focused drills, speaking diaries, speaking review, study plans, reminders, or weekly reports, read `skills/ielts-speaking-coach/SKILL.md` and follow it. For requests about all four IELTS skills, read `skills/ielts-study/SKILL.md`. The optional ordinary Doubao fallback is `skills/ielts-speaking-coach/adapters/doubao-personal-agent.md`.

User-specific learning data belongs only in the configured private workspace, default `workspace/`. Do not read unrelated personal directories. Keep personal and copyrighted materials out of Git.

For repository code maintenance, use Python 3.10+ standard library and run `python3 -m unittest discover -s tests -v`. Do not initialize a study session merely because someone is editing this repository.
