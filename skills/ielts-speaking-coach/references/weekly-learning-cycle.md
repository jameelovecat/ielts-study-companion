# 口语学习计划、提醒与周报

## 计划形成

学习计划遵循「计划 → 练习 → 复盘 → 调整」。这与自我调节学习中的计划、执行、反思循环相符；具体日程应由用户的目标、时间和实际记录决定。[Zimmerman，自我调节学习概述](https://eric.ed.gov/?id=EJ656632)

首次使用时先读已有记录，只补问缺项。没有近期成绩时优先敲定诊断模考；可以先商量一个轻量初版安排，再用模考证据调整。首次完整模考后，根据用户可用时段提出一周计划，并邀请用户确认。计划字段：星期或相对时段、目标、材料／章节、分钟数、应用练习、检查方式。

单次专项练习的反馈采用少量、及时、具体且可执行的内容；这对应形成性反馈研究的常见指导。[Shute，形成性反馈综述](https://doi.org/10.3102/0034654307313795)

## 表达回忆

将练习中真实出现的高价值搭配、句型和表达结构加入个人表达本。复习时先提供含义相近的提示，等待用户回忆和造句，再反馈并更新状态。主动提取和分散复习有学习研究支持；具体复习间隔是可调整的操作设置，不声称存在唯一通用的固定曲线。[Karpicke与Roediger，提取练习实验](https://doi.org/10.1126/science.1152408)；[Cepeda等，间隔练习综述](https://pubmed.ncbi.nlm.nih.gov/16719566/)

## 提醒规则

先与用户确认任务、频率、日期、时间和时区，再使用当前平台真实的定时任务能力。每日口语练习提醒与表达复习提醒分开开关、分别记录；同一时间同时到期时，避免重复轰炸。通知应简短，写明当天目标、预计时长和开始方式。

如果平台不能读取用户练习记录或不能无人值守运行，设置「提醒用户回到对话」的任务，不承诺自动生成学习报告。不能把消息推送当作练习完成，也不能因提醒自动更改成绩、复习等级或完成状态。

## 周报规则

报告应覆盖用户选定的一周周期，并根据已保存记录汇总：

1. 计划与实际完成；实际时长仅来自可靠计时。
2. 模考、专项训练、自由日记的次数及可观察变化。
3. 高频语法、词汇、搭配和表达结构问题，附真实例句；区分单次失误与反复模式。
4. 表达复习结果及仍到期的条目。
5. 下周一至三个目标和建议日程。

无练习记录时直说无可核对数据，不编造趋势、估分或掌握情况；不把未完成项累计成「欠账」。

## 平台限制

- **WorkBuddy**：根据当前工作区是否能读写学习文件、是否提供定时任务来启用对应流程；先确认用户允许访问的目录。
- **普通豆包（备用）**：只提供可复制到个人智能体的简短设定，是否支持语音对话以应用当前功能为准；不提供工作台Skill包，也不承诺文件读写或定时任务。
- **ChatGPT Skills**：Skills可用性取决于账号和工作区。定时任务另由ChatGPT Scheduled Tasks提供；需检查账号支持、任务限制、对话是否可用于语音等边界。

任一能力未开放时，提供可复制的周计划、周报或提醒内容作为替代。不要因为 Skill 能描述一个流程，就宣称平台已经创建了文件或定时任务。
