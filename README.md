# IELTS Study Companion · 雅思备考 Skill

**一个用于 Codex 和 Claude Code 的 Skill，帮你设计并搭建自己的雅思备考系统。**

装好后，直接说「帮我设计自己的雅思备考系统」。助手会先了解你的目标、工作节奏和已有资料，再建立学习计划、练习记录、错题本和表达复习；需要时，也可以继续帮你生成练习页面。

[查看 Skill 规则](skills/ielts-study/SKILL.md) · [查看考试页面示例](https://claude.ai/artifact/3mCLUuoCdkD6QKsn5DkAcF)

## 安装 Skill

把下面这段话复制给你的 **Codex 或 Claude Code**：

> 请帮我安装这个雅思备考 Skill：https://github.com/jameelovecat/ielts-study-companion/tree/main/skills/ielts-study 。按当前工具支持的方式安装到个人 Skill 目录。已有同名 Skill 时先告诉我，不要覆盖。安装完成后告诉我如何开始；如果需要重新打开对话才能识别，也请提醒我。

助手会处理下载和安装。需要你授权或操作时，按提示完成即可。需要可用的 Codex 或 Claude Code，工具本身可能收费。

## 装好以后，怎么用？

### 第一次：让它帮你搭建

> 帮我设计自己的雅思备考系统。我平时要上班，想利用零碎时间准备。先了解我的情况，再帮我搭建。

它会主动和你讨论考试目标、工作日每天能学多久、周末是否有更多时间，以及适合学习的时段。一起确定强度后，生成一份具体的每周日程：哪天练什么、花多久、什么时候复习。

没有考试日期也可以先做一周试行计划。日程由你确认，再保存到自己的学习文件夹里；忙的时候可以缩短任务，之后根据实际完成情况调整。

### 接入资料：把位置或链接发给它

**已经有真题？**直接说：

> 我的雅思资料在这里：［你的文件夹位置］。帮我整理并接入备考系统，保留原文件。

**还没有资料？**可以参考社区整理的 [雅思资料库 zeeklog／IELTS](https://github.com/zeeklog/IELTS)，把链接发给助手：

> 我想用这个资料库备考：https://github.com/zeeklog/IELTS 。先看看有哪些资料，帮我下载和整理需要的部分，再接入备考系统。

助手会核对题目、答案与音频的对应关系，发现缺失时告诉你。第三方资料请按其授权使用，本 Skill 不附带真题和音频。

### 以后：告诉它今天想练什么

> 我今天有30分钟，帮我安排一次练习。

> 从上次听力停下的地方继续。

> 复习今天到期的表达，一次考我一个。

助手会先读取你的学习记录，再接着练。你不用每次重新介绍自己的目标，也不必反复粘贴整套提示词。

## 这个 Skill 适合谁？

### 适合工作党，跟着你的时间走

备考不一定每天都有完整的两小时。你可以利用零碎时间练一段听力、一篇阅读或一道口语题，也可以让 AI 帮你制定学习计划，再根据实际完成情况调整。

> 我今天只有15分钟，练一点听力。
>
> 我平时工作比较忙，周末时间多一些。帮我制定一个能坚持的备考计划。

各科分别记录进度，下次继续时，助手先看你练到了哪里、最近卡在什么地方。

### 嵌入你已有的 AI 使用习惯

如果你已经习惯用大模型学习和工作，就可以把雅思备考接进来：继续用熟悉的工具，通过聊天选题、交答案、问解析、改作文、复习表达。

这套项目给助手补上持续备考所需的规则和记录。你不用每次重新介绍自己的目标，也不用反复粘贴同一套提示词。

> 上次那道题我还是没懂，为什么是 NOT GIVEN？
>
> 看一下我的错题，最近最需要注意什么？

### 在屏幕上练，也练习机考需要的操作习惯

准备机考时，在电脑上阅读、输入答案和限时写作，可以顺便熟悉屏幕阅读与键盘作答的节奏。练习之后，直接把答案或作文交给助手分析。

手机则适合补充零碎练习：复习表达、看错题、构思口语回答。如果你使用的 AI 工具支持手机访问，也可以在那里继续对话；本地资料和进度能否同步，取决于所用工具。

这里提供的是备考练习流程，界面和操作不等同于正式考试系统。

### 想要练习页面？让 AI 帮你生成

已经有一个用 Claude 生成的实际例子：**[查看考试页面示例：剑桥雅思17](https://claude.ai/artifact/3mCLUuoCdkD6QKsn5DkAcF)**。

页面提供四套题切换，按听力、阅读、写作和口语分区，带听力播放控件，并将答案与原文收在单独展开的区域里。你可以参考这种组织方式，让 AI 为自己的资料生成练习页面。

你也可以让 Codex 或 Claude Code，在这套系统的基础上生成适合自己的练习页面，把计时、答题、错题和复习放到一个界面里。

> 帮我生成一个简洁的本地雅思练习页面，可以选题、播放听力、计时和填写答案。先告诉我准备怎么做，再开始搭建。个人记录保存在本地。

**当前项目提供备考规则、记录模板和辅助脚本，还没有自带网页界面。**页面是可选扩展，需要由你的 AI 助手继续搭建和验证；手机使用还需要适配访问方式。

## 有计划，也可以有学习提醒

计划确定后，助手会问你是否需要定时提醒。例如：

> 工作日晚上八点提醒我练习，周六上午十点提醒，附上当天要做的任务。

如果当前应用支持定时任务和通知，助手会在你确认后设置，并告诉你怎样修改或暂停。能否收到手机或桌面推送，取决于所用应用及通知权限；不支持时会说明替代方式，不会只说「设置好了」。

## 每次练习，都积累自己的表达

练完不只留一个分数。助手会主动整理并保存：

| 积累什么 | 示例 |
|---|---|
| 词汇搭配 | **put time and effort into doing something**：投入时间精力做某事 |
| 句型 | **What matters most is…**：用来指出最重要的一点 |
| 回答结构 | **观点 → 原因 → 具体例子**：让回答有主线，也有细节 |

每条包含含义、示范、来源，以及你原来的说法（如有），保存到自己的表达本里，按间隔安排复习。搭配练运用，句型练造句，回答结构换一个话题再练，不只是背范文。

你可以直接说：

> 看看今天积累了哪些表达。
>
> 复习今天到期的句型，再给我一个新话题练回答结构。

## 每题都有目标，练完留下自己的口语备考本

练口语时，助手会先告诉你这题要回答什么、建议说多久，再一次问一题。点评会给你两版答案：一版保留你的观点和说话方式，只修改必要的错误；另一版提供参考思路。最后提炼常用词汇与搭配。

你可以直接说：

> 把今天练过的所有题整理进我的口语备考本，每题保留两版答案和词汇搭配。

备考本保存在你自己的学习目录里，下次可以接着重练和复习。

## 从练习到复习，连起来用

| 你想做什么 | 可以怎么说 |
|---|---|
| 安排学习计划 | 「结合我的工作时间和目标，安排接下来一周的练习。」 |
| 利用碎片时间 | 「我有15分钟，从上次听力停下的地方继续。」 |
| 分析阅读错题 | 「这道题为什么错？帮我对照题干和原文。」 |
| 练习口语 | 「扮演考官，一次问我一题，结束后再点评。」 |
| 修改作文 | 「按雅思标准给反馈，保留我的观点，指出最该改的地方。」 |
| 积累与复习表达 | 「复习今天到期的表达，一次考我一个。」 |
| 生成练习页面 | 「基于现有系统，帮我做一个适合我的练习页面。」 |

练习记录会区分「实际完成」和「只是讨论过解析」，不会因为问了一道题，就把整套题标成已完成。听力、阅读、写作和口语分别跟踪进度。

AI 的批改与估分用于辅助学习，不是官方成绩。文字口语回答无法评价发音；录音、转写、播放和计时能力取决于所用工具，需要时助手会说明并协助配置。

## 我的资料和记录呢？

默认保存在你电脑上的独立学习文件夹里，下次继续时助手会读取这些记录。个人资料和记录已设置为不随项目提交到 GitHub。

把作文、摘录或音频交给 AI 时，仍适用你使用的 AI 服务的数据政策；本地保存不代表离线处理。录音和额外的云端转写会先征得你的同意。

需要 Python 3.10 及以上版本，无第三方 Python 依赖。Codex 从 `AGENTS.md` 读取项目指令，Claude Code 从 `CLAUDE.md` 读取；两者使用同一份 `skills/ielts-study/SKILL.md`。

独立安装包为 `skills/ielts-study/`，包含规则、初始化与复习脚本、空白模板和数据格式说明，不依赖仓库外部文件。脚本以 `--workspace` 指定私有目录；未指定时默认当前工作目录下的 `workspace/`。仓库内该目录已加入 `.gitignore`。资料目录在工作区的 `config.json` 中配置，索引只发现文件，内容对应关系由助手核验。辅助脚本不提供自动评分、录音转写或网页界面。

```bash
python3 scripts/study.py init
python3 scripts/study.py index
python3 scripts/study.py due
python3 scripts/study.py review expr-demo --result correct
python3 -m unittest discover -s tests -v
```

`review` 要使用表达本中实际存在的 ID；`expr-demo` 仅为示例。可用 `--workspace /path/to/private-folder` 指定其他工作区。

更多格式见 [数据约定](docs/data-format.md)。
