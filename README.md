# IELTS Study Companion

**给忙碌的人，一个随时可以开始、下次还能接着练的雅思备考助手。**

下班后有半小时，午休有十分钟，或者今天终于能空出一整晚——告诉 AI 你有多久，让它结合你的目标和进度安排练习。做完一起分析错题，把值得记住的表达留下来，到期再复习。

用你已经在用的 **Codex 或 Claude Code** 就能开始。

## 为什么做这套系统？

### 适合工作党，跟着你的时间走

备考不一定每天都有完整的两小时。你可以利用零碎时间练一段听力、一篇阅读或一道口语题，也可以让 AI 帮你制定学习计划，再根据实际完成情况调整。

> 我今天只有15分钟，练一点听力。
>
> 我平时工作比较忙，周末时间多一些。帮我制定一个能坚持的备考计划。

各科分别记录进度，下次继续时，助手先看你练到了哪里、最近卡在什么地方。

### 嵌入你已有的 AI 使用习惯

如果你已经习惯用大模型学习和工作，就可以把雅思备考接进来：继续用熟悉的工具，通过聊天选题、交答案、问解析、改作文、复习表达。

这套项目给助手补上持续备考所需的规则和记录。你不用每次重新介绍自己的目标，也不用反复粘贴同一套提示词。

> 上次那道题我还是没懂，为什么是 NOT GIVEN？
>
> 看一下我的错题，最近最需要注意什么？

### 在屏幕上练，也练习机考需要的操作习惯

准备机考时，在电脑上阅读、输入答案和限时写作，可以顺便熟悉屏幕阅读与键盘作答的节奏。练习之后，直接把答案或作文交给助手分析。

手机则适合补充零碎练习：复习表达、看错题、构思口语回答。如果你使用的 AI 工具支持手机访问，也可以在那里继续对话；本地资料和进度能否同步，取决于所用工具。

这里提供的是备考练习流程，界面和操作不等同于正式考试系统。

### 想要练习页面？让 AI 帮你生成

已经有一个用 Claude 生成的实际例子：**[查看考试页面示例：剑桥雅思17](https://claude.ai/artifact/3mCLUuoCdkD6QKsn5DkAcF)**。

页面提供四套题切换，按听力、阅读、写作和口语分区，带听力播放控件，并将答案与原文收在单独展开的区域里。你可以参考这种组织方式，让 AI 为自己的资料生成练习页面。

这是独立的 Claude Artifact 示例，未接入本项目的学习进度与表达本；页面内标注为私人练习使用，请勿转存或分发其中的真题资料。播放控件与资料加载情况以实际访问为准。

你也可以让 Codex 或 Claude Code，在这套系统的基础上生成适合自己的练习页面，把计时、答题、错题和复习放到一个界面里。

> 帮我生成一个简洁的本地雅思练习页面，可以选题、播放听力、计时和填写答案。先告诉我准备怎么做，再开始搭建。个人记录保存在本地。

**当前项目提供备考规则、记录模板和辅助脚本，还没有自带网页界面。**页面是可选扩展，需要由你的 AI 助手继续搭建和验证；手机使用还需要适配访问方式。

## 三步开始

### １．把项目交给你的 AI 助手

复制下面这段话，发给 Codex 或 Claude Code：

> 请帮我下载并配置这个雅思备考项目：https://github.com/jameelovecat/ielts-study-companion 。在电脑上为它单独建一个文件夹，阅读项目里的备考规则，完成初始化，并检查需要的工具。先了解我的考试类型、目标和每天能练习多久。没有考试日期也可以先开始。能直接完成的步骤请帮我完成，需要我操作时一次只告诉我一步。

如果工具需要你授权访问文件夹或联网，按提示操作即可。需要可用的 Codex 或 Claude Code，工具本身可能收费。

### ２．提供自己的资料

**已经有真题？**把资料文件夹的位置发给助手，说：

> 我的雅思资料在这里：［你的文件夹位置］。帮我整理并接入备考系统，保留原文件。完成后告诉我有哪些题可以练。

**还没有资料？**可以参考社区整理的 [雅思资料库 zeeklog／IELTS](https://github.com/zeeklog/IELTS)，里面有真题、听力音频和写作资料。把链接发给助手，说：

> 我想用这个资料库备考：https://github.com/zeeklog/IELTS 。先看看里面有哪些资料，帮我下载和整理需要的部分，再接入备考系统。

助手会核对题目、答案与音频的对应关系，发现缺失时告诉你。第三方资料的版权归原作者及出版方所有，使用时请遵守其授权。本项目不附带真题与音频。

### ３．告诉它你今天有多久

> 我今天有30分钟，帮我安排一次练习。

助手会结合你的目标、资料和已有进度推荐题目。你准备好后开始，做完一起看错题。

## 从练习到复习，连起来用

| 你想做什么 | 可以怎么说 |
|---|---|
| 安排学习计划 | 「结合我的工作时间和目标，安排接下来一周的练习。」 |
| 利用碎片时间 | 「我有15分钟，从上次听力停下的地方继续。」 |
| 分析阅读错题 | 「这道题为什么错？帮我对照题干和原文。」 |
| 练习口语 | 「扮演考官，一次问我一题，结束后再点评。」 |
| 修改作文 | 「按雅思标准给反馈，保留我的观点，指出最该改的地方。」 |
| 积累与复习表达 | 「复习今天到期的表达，一次考我一个。」 |
| 生成练习页面 | 「基于现有系统，帮我做一个适合我的练习页面。」 |

练习记录会区分「实际完成」和「只是讨论过解析」，不会因为问了一道题，就把整套题标成已完成。听力、阅读、写作和口语分别跟踪进度。

AI 的批改与估分用于辅助学习，不是官方成绩。文字口语回答无法评价发音；录音、转写、播放和计时能力取决于所用工具，需要时助手会说明并协助配置。

## 我的资料和记录呢？

默认保存在你电脑上的独立学习文件夹里，下次继续时助手会读取这些记录。个人资料和记录已设置为不随项目提交到 GitHub。

把作文、摘录或音频交给 AI 时，仍适用你使用的 AI 服务的数据政策；本地保存不代表离线处理。录音和额外的云端转写会先征得你的同意。

## 开源，一起改进

你可以使用、修改这套系统，也可以把适合自己的改进分享回来。欢迎提交 Issue 或 Pull Request，请用虚构示例说明问题，不附私人记录或版权真题。

<summary>开发者说明（普通使用者可以跳过）</summary>

需要 Python 3.10 及以上版本，无第三方 Python 依赖。Codex 从 `AGENTS.md` 读取项目指令，Claude Code 从 `CLAUDE.md` 读取；两者使用同一份 `skills/ielts-study/SKILL.md`。

默认私有工作区为 `workspace/`，已加入 `.gitignore`。资料目录在工作区的 `config.json` 中配置，索引只发现文件，内容对应关系由助手核验。辅助脚本不提供自动评分、录音转写或网页界面。

```bash
python3 scripts/study.py init
python3 scripts/study.py index
python3 scripts/study.py due
python3 scripts/study.py review expr-demo --result correct
python3 -m unittest discover -s tests -v
```

`review` 要使用表达本中实际存在的 ID；`expr-demo` 仅为示例。可用 `--workspace /path/to/private-folder` 指定其他工作区。

更多格式见 [数据约定](docs/data-format.md)。
