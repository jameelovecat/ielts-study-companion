# IELTS Study Companion · 雅思备考 Skill

**用你自己的 Codex 或 Claude Code，搭建一套适合你的雅思备考系统。**

忙的时候练15分钟，有空时做一套真题。让AI帮你安排计划、分析错题，把练习中的词汇搭配和表达结构留下来，再按节奏复习。

## 先了解起点，再推荐怎么学

带上近期成绩或完整真题记录；没有的话，助手会先选好未做过的真题，说明模测内容和用时，与你敲定一次测试。先知道起点，再讨论长期日程。无法连续完成时，再协商分次诊断。

教材推荐对应实际问题：先核对教材目录和相关章节，说明为什么适合你、先学哪里、需要多少时间，再由你确认。不必自己筛一长串资料，也不必从头学完所有教材；练习后还会检查方法是否有效，必要时调整。

## 三个学习模块

| 模块 | 做什么 |
|---|---|
| **真题练习** | 计时做题、批改解析，跟踪各科进度 |
| **复习** | 按间隔重复复习错题、词汇搭配、句型和回答结构 |
| **分项学习** | 分听力、阅读、口语、写作，学习题型方法、评分标准与答题思路，结合小练习应用 |

分项学习默认根据诊断推荐主教材，每科优先一本或一门课程，说明推荐理由与先学章节；你已有教材或偏好，也可以直接使用。确认后按章节带学、记录进度，下次接着学。

分项学习参考 [zeeklog资料站](https://zeeklog.github.io/IELTS/)及其推荐资料，教学标注具体来源。批改结合官方评分描述、该套真题答案、参考范文与可用的考官点评；范文用来学习，不要求与你的答案相同。详见[学习来源与批改依据](skills/ielts-study/references/learning-and-assessment.md)。

## 为什么用它备考？

### 适合工作党，按自己的时间来

备考不一定每天都有完整的两小时。工作日半小时、午休十分钟、周末一整段时间，都可以安排不同的练习。

助手会先和你讨论目标、工作日与周末能投入多久，再一起确定每周日程。当天忙不过来，可以缩短任务；下次接着已有进度练，不必重新开始。

### 融入你已经在用的AI工具

如果你已经习惯用Codex或Claude Code学习、工作，就可以直接把备考接进来。

安装Skill后，用聊天的方式选题、交答案、问解析、改作文。学习目标、各科进度和常见问题会保存在自己的学习记录里，你不用每次重新解释「我学到哪里了」。

### 练完有积累，下次有复习

每次练习之后，助手不仅分析对错，还会整理值得复用的词汇搭配、句型和回答结构，结合你原来的说法给出示范。

口语点评有两版：**一版尽量保留你的观点和表达，只修正必要错误；另一版提供参考思路。**你也可以把当天练过的题汇总成自己的口语备考本。

错题与表达通过间隔重复安排复习，先尝试回答，再看反馈。学习计划确定后，还可以分别设置「真题练习」和「到期复习」提醒，时间由你确认，具体通知能力取决于所用应用。

### 在电脑上练，熟悉屏幕阅读与输入

准备机考时，在电脑上读题、输入答案、限时写作，也是在熟悉屏幕阅读和键盘作答的节奏。练完直接让助手分析，减少来回整理的步骤。

如果所用工具支持手机访问和记录同步，也可以用手机复习表达、看错题，利用零碎时间。练习页面与正式考试系统并不完全相同。

## 怎么用？

### １．安装Skill

把下面这段话复制给你的 **Codex或Claude Code**：

> 请帮我安装这个雅思备考Skill：https://github.com/jameelovecat/ielts-study-companion/tree/main/skills/ielts-study 。按当前工具支持的方式安装到个人Skill目录。已有同名Skill时先告诉我，不要覆盖。安装完成后告诉我如何开始；如果需要重新打开对话才能识别，也请提醒我。

### ２．一起确定计划，接入资料

装好后，直接说：

> 开始雅思备考。

助手会先了解考试类型、目标与近期成绩。没有成绩就先敲定一次真题模测，诊断后再推荐教材、确认章节和日常安排。考试日期尚未确定也可以开始。

已经有资料，就把文件夹位置发给助手，让它整理并接入。

还没有资料，可以参考社区整理的 [zeeklog／IELTS雅思资料库](https://github.com/zeeklog/IELTS)，把链接发给助手，请它查看并整理需要的部分。

### ３．开始练习，接着复习

你可以直接说：

- 「我今天有30分钟，从上次停下的地方继续。」
- 「今天先学阅读判断题的方法，给我一个小练习，并标明来源。」
- 「这道题为什么错？帮我对照原文解释。」
- 「把今天的口语答案和词汇搭配整理进备考本。」
- 「复习今天到期的表达，一次考我一个。」
- 「帮我设置真题练习和复习提醒，先确认时间。」

## 定制自己的真题练习页面

做题时，一会儿打开PDF，一会儿找对应音频，做完又要翻到答案和原文——资料分散，来回切换很不方便。

可以让AI帮你把它们汇总到一个页面：按套题、科目和部分切换，点击播放对应音频，随时找到题目，做完再展开答案和原文。你也可以按自己的习惯增加计时、答题区和错题入口，让练习更直观。

**[看看我用Claude生成的页面：剑桥雅思17](https://claude.ai/artifact/3mCLUuoCdkD6QKsn5DkAcF)**

想做自己的版本，可以说：

> 帮我把本地真题、对应音频、答案和原文整理成一个练习页面，可以按套题和科目切换，答案默认收起。先核对资料对应关系，再和我确认页面功能，最后搭建并测试。

页面由你的AI助手按需生成，Skill本身不自带现成网页。计时、答题保存等功能需要实际搭建和验证。

## 简短说明

- 需要可用的Codex或Claude Code，工具本身可能收费。
- 本项目不附带真题和音频，第三方资料按其授权使用。
- 个人资料与学习记录默认保存在本地，不随项目上传GitHub；交给AI的内容仍适用相应服务的数据政策。
- AI批改和估分用于辅助学习，不等同于官方成绩。
