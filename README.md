# IELTS Study Companion

用你自己的 Codex 或 Claude Code，搭建一个记得学习进度的雅思备考助手。

**告诉它你有多久 → 练真题 → 分析错因 → 积累表达 → 到期复习。**

你只需要能使用 Codex 或 Claude Code。把项目交给它，用聊天的方式开始备考；文件整理和环境配置由助手协助完成。AI 工具本身可能收费。

## 三步开始

### １．把项目交给你的 AI 助手

复制下面这段话，发给 Codex 或 Claude Code：

> 请帮我下载并配置这个雅思备考项目：https://github.com/jameelovecat/ielts-study-companion 。在电脑上为它单独建一个文件夹，阅读项目里的备考规则，完成初始化，并检查需要的工具。先了解我的考试类型、目标和每天能练习多久。没有考试日期也可以先开始。能直接完成的步骤请帮我完成，需要我操作时一次只告诉我一步。

如果工具需要你授权访问文件夹或联网，按提示操作即可。

### ２．提供自己的资料

**已经有真题？**把资料文件夹的位置发给助手，说：

> 我的雅思资料在这里：［你的文件夹位置］。帮我整理并接入备考系统，保留原文件。完成后告诉我有哪些题可以练。

**还没有资料？**可以先参考社区整理的 [雅思资料库 zeeklog／IELTS](https://github.com/zeeklog/IELTS)，包含真题、听力音频和写作资料。把这个链接发给助手，说：

> 我想用这个资料库备考：https://github.com/zeeklog/IELTS 。先看看里面有哪些资料，帮我下载和整理需要的部分，再接入备考系统。

助手会核对题目和音频的对应关系，发现缺失资料时告诉你。第三方资料的版权归原作者及出版方所有，使用时请遵守其授权。

### ３．开始练习

直接告诉助手：

> 我今天有30分钟，帮我安排一次练习。

它会结合你的目标、资料和已有进度推荐题目。你准备好后再开始，做完一起看错题。

## 你可以直接说

- 「我有 30 分钟，安排今天的练习。」
- 「我做完了剑 18 Test 1 听力 Section 2，帮我批改。」
- 「这道判断题为什么是 NOT GIVEN？给我看定位句。」
- 「练一套口语，一次问我一题。」
- 「帮我批改这篇作文，保留我的观点。」
- 「复习今天到期的表达。」

默认先了解你、再建议学习顺序；不固定从某册开始。考试类型未确认时，不混用 Academic 与 General Training 的阅读、写作材料。

## 能做什么

| 功能 | 工作方式 |
|---|---|
| 按时间安排 | 根据最近记录、弱项和可用时间推荐练习 |
| 听力、阅读 | 从你的资料定位题目、答案和原文，批改并解释错因 |
| 写作 | 词数、四项反馈、估分与保留原意的修改 |
| 口语 | 考官一问一答；文字回答无法评估发音 |
| 学习记录 | 各科分别跟踪进度，区分完成、计划和仅讨论 |
| 表达复习 | 本地词条，按到期日抽查，脚本更新复习间隔 |

AI 负责对话与解析，Python 脚本负责初始化、文件索引及复习日期计算。**不是自动评分引擎，也不保证提分或官方评分精度。**录音、转写和计时取决于所在工具环境；没有实际计时能力时使用者自行设定计时器，助手不能声称有后台提醒。

## 我的记录存在哪里？

学习档案、错题本、表达本和个人作品默认保存在电脑上的独立学习文件夹里，下次继续时助手会先读取这些记录。它们不会随本项目提交到 GitHub。

把作文、摘录或音频交给 AI 时，仍适用你所使用 AI 服务的数据政策。录音和额外的云端转写会先征得你的同意。

本项目以 MIT 许可证开放代码、指令和模板，不附带真题与音频。

<summary>开发者说明与辅助命令（普通使用者可以跳过）</summary>

需要 Python 3.10 及以上版本，无第三方 Python 依赖。Codex 从 `AGENTS.md` 读取项目指令，Claude Code 从 `CLAUDE.md` 读取；两者使用同一份 `skills/ielts-study/SKILL.md`。

默认私有工作区为 `workspace/`，已加入 `.gitignore`。资料目录在工作区的 `config.json` 中配置，索引只发现文件，内容对应关系由助手核验。

## 辅助命令

```bash
python3 scripts/study.py init
python3 scripts/study.py index
python3 scripts/study.py due --date 2026-11-01
python3 scripts/study.py review expr-demo --result correct --date 2026-11-01
python3 -m unittest discover -s tests -v
```

`review` 要使用表达本中实际存在的 ID；`expr-demo` 仅为示例。默认工作目录为当前项目的 `workspace/`，可用 `--workspace /path/to/private-folder` 指定其他位置。

更多格式见 [数据约定](docs/data-format.md)。想分享改进，欢迎提交 Issue 或 Pull Request；请使用虚构例子复现问题，勿附版权真题或私人数据。
