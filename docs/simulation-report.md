# 首次使用模拟报告

日期：2026年11月1日。使用临时独立Skill副本与虚构数据，不涉及本人学习记录。

## 已验证

- 独立安装包初始化成功，未依赖仓库其他文件。
- 资料索引发现1个自拟文件；没有真实题目与答案，不生成诊断成绩或声称已推荐教材。
- 诊断、计划与课程记录模板存在；新用户下一步应提供实际资料，或授权读取选定来源。
- 三类表达可进入同一复习队列；到期筛选不泄露答案；答对延后2天、答错次日重试。
- 再次初始化没有覆盖已有学习档案。
- 私有工作区的表达本被上级Git仓库忽略。

## 未覆盖

- 没有完整真实真题，因此未做实际教学与评分校准。
- 未创建通知；须先确认两个时段且验证当前应用的定时能力。
- 此模拟由当前助手执行，不等同于新用户或独立模型的可用性测试。

## 对话路径检查（模拟，不是实际学习成绩）

| 场景 | 应有行为 | 检查结论 |
|---|---|---|
| 用户工作日只有30分钟，尚无成绩 | 分次诊断，记录条件，不硬塞整套考试 | 补明确了分次状态与下一次任务 |
| 诊断只完成一部分 | 暂定轻量日程，待补齐后确认教材，不外推总分 | 已写入Skill |
| 用户想直接学自己已有的书 | 核对目录与内容，使用该教材而非强制推荐 | 规则已覆盖，需真实资料验证教学 |
| 用户让助手直接评分但没有题目或答案 | 请求缺失材料，不编分数与依据 | 规则已覆盖，未运行真实评分 |
| 同日复习先对后错 | 回0级，次日再练 | 已通过命令验证 |
| 用户希望手机定时提醒 | 确认时间、时区与渠道，再核验平台支持 | 未创建实际任务 |
| 用户新对话说继续 | 读取原工作区，缺少位置时才询问 | 补充续接规则 |

对话路径是基于Skill的人工走查，不是独立模型执行或界面端到端测试。
